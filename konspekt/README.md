# konspekt — библиотека для учебных конспектов на Typst

Правила содержания (что писать и как проверять) — в `CLAUDE.md` в корне проекта.
Здесь только о том, как пользоваться библиотекой.

Проверено на Typst 0.15.1. Единственная внешняя зависимость — `@preview/cetz:0.4.2`
(лежит в кэше `~/.cache/typst/packages`, работает офлайн).

## Быстрый старт

1. Завести проект копией каталога `~/Documents/code/projects/konspekt-style/`: в нём уже есть
   `CLAUDE.md` (правила), `lib/` (библиотека), `typst/` (исходники) и `Makefile`.
2. Шрифты заданы в `theme.typ`. Каких нет в системе — typst наберёт
   запасными из того же списка, сборка не падает.
3. `typst/main.typ`:

```typst
#import "../lib/lib.typ": *

#show: конспект.with(
  тема: темы.классика,          // классика | ночь
  вид: [Конспект],              // надпись над названием на титуле (Задачник, Шпаргалка…)
  название: [Кратные интегралы],
  подзаголовок: [Двойные, тройные и $n$-мерные интегралы],
  автор: [Математический анализ · 2 семестр],
  дата: [2026],
  описание: [Для кого конспект и как его читать — 2–3 фразы на титул.],
  титул: true,
  оглавление: true,
  глубина: 2,                    // уровни заголовков в оглавлении
)

#include "01-повторение.typ"
#include "02-двойной.typ"
```

4. Каждая глава начинается так:

```typst
#import "../lib/lib.typ": *

= Двойной интеграл
#лид[...]
#план([...], [...], [...])
== Задача об объёме
...
```

5. Сборка: `make` (тема «классика»), `make ночь`, `make watch`. Под капотом
   `typst compile --root . typst/main.typ`; `--root .` обязателен: `код-из-файла`
   и ссылки на файлы считаются от корня проекта.

Правила содержания — в `CLAUDE.md` в корне: в его шапке записываются курс, цель,
слабые темы и текущее состояние работы.

## Темы

| Тема | Характер |
|---|---|
| `классика` | развитие конспекта по матану: синий акцент, врезки с полосой, книжный абзац |
| `ночь` | **та же вёрстка, другая палитра**: тёмная страница для чтения с экрана |

«Ночь» получена из «классики» одним `настроить(классика, (цвет: …))`: шрифты,
кегли, поля, заголовки, врезки и колонтитулы у них общие. Один конспект в двух
видах должен выглядеть одним конспектом.

Раньше были ещё темы «книга» (поле для заметок) и «инженер»
(карточки) — они лежат в `../архив/` вместе с их PDF (в проекте-копии
этой папки нет).

Своя тема — глубокое слияние с существующей, указывать только то, что меняется:

```typst
#let моя = настроить(темы.классика, (
  цвет: (акцент: rgb("#7a1f5c"), рис: (линия: rgb("#7a1f5c"))),
  кегль: (текст: 11.5pt),
))
#show: конспект.with(тема: моя, ...)
```

Устройство темы (палитра, шрифты, кегли, поля) — в `theme.typ`. Вёрстка одна на
все темы, поэтому своя тема — это только палитра.

## Блоки (`blocks.typ`)

| Вызов | Что это |
|---|---|
| `#опр(заголовок: "…")[…]` | определение; нумеруется «глава.n», вместе с теоремами |
| `#теорема(заголовок: "…")[…]` | теорема / утверждение |
| `#доказательство[…]` | эскиз доказательства, мельче, с ∎ |
| `#пример(заголовок: "…")[…]` | разобранный пример; нумеруется отдельно |
| `#шаг[Название]` | внутри примера: «Шаг 1. Название.», своя нумерация в каждом примере |
| `#ответ[…]` | ответ в рамке, прижат вправо |
| `#замечание[…]`, `#идея[…]`, `#алгоритм[…]`, `#ошибка[…]` | ненумерованные врезки |
| `#формула(подпись: "…")[$ … $]` | ключевая формула в рамке — одна-две на раздел |
| `#лид[…]` | 2–4 вводных предложения главы |
| `#план([…], […], […])` | «В этой главе»: что научимся делать |
| `#итог([…], […])` | «Коротко о главном» в конце главы |
| `#вопросы(([вопрос], [ответ]), …)` | «Проверь себя», ответы мелко внизу блока |
| `#ошибки(([ошибка], [как избежать]), …)` | таблица типичных ошибок ✗/✓ |
| `#таблица(колонки, шапка: (…), выделить: ("4,*": "третий"), …ячейки)` | таблица с подсветкой клеток, строк («4,\*») и столбцов («\*,2») — трассировки алгоритмов |
| `#на-полях[…]` | мелкая заметка сбоку от мысли |
| `#рядом[текст][рисунок]` | текст и небольшой рисунок рядом, в две колонки |
| `#капитель[…]` | капитель для кириллицы (у шрифтов нет своей, `smallcaps` не работает) |

Определения и теоремы не рвутся между страницами. Примеры рвутся.

## Код (`code.typ`)

```typst
#листинг(
  подпись: [построение P],
  выделить: (5, 6),              // подсветить строки
  метки: ("5": 1, "12": 2),      // кружки ① ② у строк
  сложность: [$O(n m)$],
  ```cpp
  ...
  ```,
)
Строка #метка(1) — формула построения.   // ссылка на метку из текста

#код-из-файла("/code/prefix.cpp", регион: "build", выделить: (3,))
```

- Подсветка берётся из цветов темы, лигатуры выключены.
- Листинг до 15 строк не рвётся между страницами.
- `код-из-файла` берёт кусок между `// region: имя` и `// endregion: имя`.
  Путь указывается от корня проекта и начинается с `/`. Нет региона — сборка
  падает с понятной ошибкой.

## Рисунки (`figures.typ`, на cetz 0.4.2)

```typst
#рис(
  холст(масштаб: 2.5cm, т => {          // т — текущая тема
    import cetz.draw: *
    область(x => x * x, x => x, 0, 1)   // заливка между кривыми
    оси(x: (-0.1, 1.3), y: (-0.1, 1.2))
    график(x => x * x, 0, 1.08, подпись: $y = x^2$, подпись-x: 0.9, якорь: "north-west")
    спица(0.6, 0.36, 0.6)               // двусторонняя стрелка
    засечка(1, $1$)
    line((0, 0), (1, 1), stroke: 1pt + т.цвет.рис.второй)   // свои линии — цветами темы
  }),
  [Подпись — утверждение о том, что видно],
  метка: "рис-спица",                    // в тексте: рис. @рис-спица
  плавающий: false,                      // true — рисунок встанет вверх/вниз страницы
)
```

| Помощник | Назначение |
|---|---|
| `оси`, `засечка`, `график`, `кривая`, `область`, `спица`, `точка` | 2D: оси через начало координат, функции, параметрические кривые, заливки |
| `линии-уровня(f, уровни, xr:, yr:)` | горизонтали поверхности (marching squares) |
| `п3`, `оси3d`, `поверхность(f, xr, yr, вид: "свет"/"грани"/"сетка")`, `столбики`, `основание`, `вращение(r)`, `сечение(f, y0)` | псевдо-3D, алгоритм художника |
| `массив(значения, выделить:, отрезки:, указатели:, блок:, своды:, дуги:)` | одномерный массив: блоки и своды (sqrt-декомпозиция), дуги (обмен, ссылка), указатели |
| `сетка(матрица, прямоугольники:, клетки:, стрелки:, значения:)` | матрица и таблица ДП: подсветка клеток и стрелки переходов |
| `граф(вершины, рёбра, ориентированный:, выделить:, метки:, форма:)` | граф; узлы кругом или прямоугольником (две строки: ключ и приоритет); встречные рёбра разводятся сами |
| `раскладка-дерево(рёбра, корень)`, `раскладка-бинарное(дети, корень)` + `рёбра-бинарного(дети)`, `раскладка-круг(имена)` | координаты вершин: по уровням, по порядку ключей (деревья поиска, декартовы деревья), по окружности |
| `в-ряд(…, разделители: ($=$, $-$))` | несколько холстов в ряд: кадры алгоритма, формула из картинок |

## Диаграммы по данным (`charts.typ`)

Когда данные — не функция, а измерения: время работы, размеры, доли.
Диапазоны, засечки «круглым» шагом, сетка и легенда считаются сами.

```typst
#рис(холст(диаграмма(
  (вид: "ломаная", точки: true, подпись: [перебор], данные: ((1, 10), (2, 40), (3, 90))),
  (вид: "функция", f: x => x * calc.log(x), от: 1, до: 5, подпись: [$n log n$]),
  ширина: 5.2, высота: 3.2, подписи: ([$n$], [мс]), легенда: "внутри",
)), [Что показывает диаграмма])
```

Виды рядов: `ломаная` (`точки: true`, `пунктир: true`), `точки`, `ступени`
(функция распределения, ступенчатые оценки), `столбцы` (данные —
`((подпись, значение), …)`), `функция` (`f`, `от`, `до`).
Прочее: `x`, `y` (диапазоны, по умолчанию по данным), `засечки-x`, `засечки-y`,
`формат-x`, `формат-y`, `сетка`, `легенда` («справа», «внутри», `none`).

Цвета задаются именами `"линия"`, `"второй"`, `"третий"`, `"акцент"` или типом `color`.
Имена превращаются в цвета текущей темы, поэтому один и тот же рисунок работает в любой теме.

**Оси:** y смотрит вверх во всех помощниках, кроме `сетка` и `массив` (там
строки идут сверху вниз). **3D:** x вправо, z вверх, y уходит влево-вверх,
«от нас».

Внутри `import cetz.draw: *` имена `line`, `rect`, `content`, `fill`, `stroke`
заняты функциями cetz — не называй так свои переменные.

## Математика (`math.typ`)

- `tg ctg arctg arcctg sh ch th cth rot grad const` — операторы в русской традиции.
- `dc("0,5")` — десятичная дробь с запятой. **Не** `$0,5$`: typst напечатает «0, 5».
- `dd(x)` — дифференциал.

## Проверка

```sh
python3 lib/lint.py          # сырые запятые в формулах, {,}, smallcaps
pdftoppm -r 70 -png конспект.pdf /tmp/стр   # и посмотреть страницы глазами
```

## Файлы

```
lib.typ        точка входа (#import "../lib/lib.typ": *)
theme.typ      темы «классика» и «ночь», настроить(), доступ к текущей теме
template.typ   конспект.with(...): страница, заголовки, колонтитулы, таблицы, титул
blocks.typ     врезки, лид/план/итог/вопросы, заметки сбоку, таблицы с подсветкой
code.typ       листинги, метки, код из файла
figures.typ    холст, 2D/3D, массивы, матрицы, графы и деревья
charts.typ     диаграммы по данным
math.typ       операторы, dc()
lint.py        линт исходников
README.md      этот файл
```
