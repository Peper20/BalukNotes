# tests/vault — хранилище-фикстура

Тестовое хранилище: на нём работают сквозные тесты (`crates/*/tests/`),
эталонные снимки (`tests/snapshots/`), визуальная проверка
(`tools/visual.mjs`) и тестовое окружение (`tools/test-env.sh`).
Демонстрационное хранилище с конспектами — отдельно, в `data/vault/`.

**Каждый файл здесь что-то проверяет.** Добавили случай — допишите строку в
таблицу, обновите снимки (`UPDATE_SNAPSHOTS=1 cargo test -p notes-core --test
snapshots`) и, если меняется число проблем, ожидания в
`crates/notes-core/tests/vault.rs` (`check_finds_exactly_the_planted_problems`).

## Намеренные проблемы

`notes --vault tests/vault check` должен найти ровно это (код выхода 1):

| Заметка | Проблема |
|---|---|
| `Особые случаи/Ошибка компиляции` | ошибка: неизвестная функция; битая ссылка `Нет/Из несобравшейся` (ссылки несобравшейся заметки — по исходнику) |
| `Особые случаи/Предупреждение` | предупреждение Typst (`#h(1fr)` в HTML) и два — проверки приложения: `lang: "uk"` без словаря и без `words:`; `;` после `#see(…)` пропадает |
| `Особые случаи/Ссылки` | битая ссылка на заметку и битый якорь |
| `Сеть/UFW` | битая ссылка `Сеть/Nginx` |

Итог — последняя строка вывода. Его сверяют `tools/check.sh` и тест
`check_finds_exactly_the_planted_problems`; новая заметка или проблема —
поправить здесь:

Итог: `заметок: 20, ошибок: 1, предупреждений: 3, битых ссылок: 4`

## Каталог

| Файл | Что проверяет |
|---|---|
| `Сеть/SSH.typ` | обычная заметка: теги, якоря заголовков, ссылки с якорем, рисунок, склеенный по цветам |
| `Сеть/UFW.typ` | ссылка с якорем и своей подписью; битая ссылка |
| `демо/компоненты.typ` | все блоки библиотеки, листинги, цвета кода, плотные скобки в формулах |
| `демо/визуализация.typ` | все виды рисунков: диаграммы, графики, 3D, массивы, графы, деревья; точность рисунков |
| `ассессмент/01-тесты.typ` | большая глава с `book` (вне книги): код из файлов `code/` |
| `Книга/` | книга (`main.typ` + главы): титул, главы `k-h1`, одинаковые «Итоги» в каждой главе → `Итоги`, `Итоги-2`, `Итоги-3`; метка `<особый>` → `id`; `code-from-file` с регионом (`code/сумма.rs`); картинка из файла (`img/схема.svg`); ссылки внутри книги |
| `Особые случаи/Без шаблона.typ` | чистый Typst без библиотеки: заголовки попадают в оглавление, формулы |
| `Особые случаи/Ошибка компиляции.typ` | ошибка с файлом и строкой; заглушка «Не собралось»; `notes check` проверяет её ссылки по исходнику |
| `Особые случаи/Предупреждение.typ` | предупреждение Typst (дробный `h`) и предупреждения проверки `lint` (язык без словаря, `;`); абсолютные `#h`/`#v` → `span.k-h`/`div.k-v` (отрицательный тоже), `quad` в формуле не трогается |
| `Особые случаи/English/` | книга с `lang: "en"`: слова оформления («Definition», «Step», «Fig.», «Chapter», «Notes», «frame 1 of 2») — из словаря `i18n.typ`; `lang` у `<article>` |
| `Особые случаи/Свои слова.typ` | `lang: "de"` (словаря нет) со своими `words:`: «Definition», «Beispiel», «Schritt», «Abb.»; чего нет в `words:` («Замечание») — из русского словаря; предупреждения нет |
| `Особые случаи/Ссылки.typ` | все виды `#see`: по тексту, по метке, в главу книги, на имена с `+ # %`, на раздел со знаками в названии, вглубь, вычисляемый путь (обратные ссылки — из собранной страницы); битые; повтор заголовков; `\;` после вызова |
| `Имена/C++ и C#.typ` | пробелы, `+`, `#` в имени: кодирование адресов; заголовки «C», «C++», «C#» — разные якоря (`C`, `C-plus-plus`, `C-sharp`) |
| `Имена/50% готово.typ` | `%` в имени: двойное декодирование адреса |
| `Имена/_черновик.typ` | служебный файл (`_`) — не заметка |
| `Глубоко/а/б/в/г/Дно.typ` | пять уровней вложенности в дереве |
| `Рисунки/Темы и градиент.typ` | рисунок, чья форма зависит от темы (запасной путь: SVG на тему); градиент; обычный рисунок рядом |
| `Рисунки/Интерактив.typ` | интерактивные рисунки (`k-plot`): график с ползунками, несколько кривых, разрывы (tg, 1/x, корень), поверхность; таблица значений, посчитанных Typst, — эталон разборщика формул клиента (Vitest) |
| `Рисунки/Граф хранилища.typ` | `vault-graph`: граф хранилища по фильтру (соседи заметки; папка без ненаписанных) — данные из `/_vault/graph/…`, рисует CeTZ, `div.k-graph[data-k-graph]` для клиента; версия — по ответу графа (пересобирается, только когда граф изменился) |
| `Рисунки/Кадры.typ` | кадры (`k-frames`): диапазон целых (суммы Римана), дробный шаг со своей подписью и `loop`, явные значения (шаги сортировки); без JS и в PDF — кадр по умолчанию |
| `Формулы и теги.typ` | заметка в корне; теги (с пробелом); высокие скобки, матрицы, системы, `dc`, русские операторы; формула и выделение в заголовке (оглавление — HTML заголовка) |
| `_служебное/`, `.скрытое/` | служебные папки — не видны в дереве |
