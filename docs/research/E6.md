# E6 - Graph layout: Barnes-Hut

The task (roadmap M3): the core layout (`notes-core::vault_graph::layout`)
several times faster, the look no worse, deterministic (one layout for the
client and `#vault-graph` in PDF).

## Method

`cargo test -p notes-core --release --lib layout_bench_synthetic -- --ignored --nocapture`.
A synthetic graph as in a vault: folders (nodes in a row), links inside a
folder (a chain and bridges), a ring between folders, four hubs with links
across the vault, some nodes without links; labels of 8-33 characters.
Measures: time (forces and label spreading), the average edge length, the
area per node, label overlaps, folder separation (the average distance between
folder centers / the average spread inside a folder - larger is better). A
laptop i5-13420H, two runs each.

## Before

Repulsion - only pairs closer than four edges (a grid), attraction to the
center `0.02 r`, the start - a circle, 400 steps. A large graph shrinks:
repulsion is not long-range, attraction grows with size.

## After

- Repulsion `EDGE²/d` of all pairs, a Barnes-Hut quadtree (`theta 0.9`).
- Attraction to the center `π EDGE² / AREA`: in equilibrium ~`AREA` (12 000)
  of area per node for any graph size.
- The start - nodes in order (by path) along a Hilbert curve of the same
  density: folders start in clusters. 60 steps, the node step 40 -> 2.
- Label spreading - as before.

Rejected: global repulsion with weak attraction (the graph spreads out: an
edge of 885 for 1000 nodes, the first variant); a spiral start from the node
of the highest degree (the hub mixes folders: separation 0.23) or a spiral in
order (folders become rings, 0.60); an area of 9000 (overlaps remain,
spreading takes longer); 200 steps (edges ~25% shorter, time x3).

Of the 60 ms for 1000 nodes: forces - 34, spreading - 25.

## Conclusion

5 times faster on 1000 nodes, 10 times on 5000; labels do not overlap at any
size (before - hundreds and thousands), folders are separated no worse. Edges
are longer: the graph is roomier (on large ones the old one was cramped -
hence the overlaps), and 60 steps do not fully untangle the long links of the
hubs. How it looks - the user looks.
