# Архитектура

Приложение для заметок на Typst: красивые заметки в стиле konspekt, всё лучшее
из Obsidian (ссылки, граф, быстрый переход, поиск) и интерактив, которого нет в PDF.
Платформы: браузер, десктоп, Android (iOS — по остаточному принципу).

## Приоритеты

1. **Отрисовка** Typst-заметок в HTML так же красиво, как PDF konspekt-style.
2. Навигация: дерево, вкладки, быстрый переход, поиск, обратные ссылки, граф.
3. Интерактив: 2D/3D графический калькулятор, анимации, ползунки.
4. Android. Потом сервер на VPS: веб-версия, синхронизация, много пользователей.
5. Когда-нибудь: встроенный редактор, история версий, бекапы, шифрование.

Заметки пишет в основном Claude Code, приложение их **показывает**. Поэтому
файлы на диске — источник правды, а приложение ничего не меняет молча.

## Решения

### 1. Rust + Tauri 2, фронтенд на TypeScript

- Typst — библиотека на Rust. Компилятор встраивается в приложение, версия
  закреплена в `Cargo.toml`. Экспериментальный HTML-экспорт не сломается от
  обновления системного `typst`.
- Tauri 2 даёт десктоп и Android из одного проекта. Electron мобильных не умеет.
- Интерфейс — один на все платформы: TypeScript, веб-технологии. Он общается
  с «бекендом» через узкий интерфейс: в Tauri это IPC к встроенному ядру,
  в браузере — HTTP к серверу с тем же ядром.

```
                ┌──────────── интерфейс (TS) ────────────┐
                │  дерево · вкладки · граф · поиск · тема │
                └───────────────┬────────────────────────┘
                   Tauri IPC    │    HTTP
          ┌─────────────────────┴──────────────────────┐
   ┌──────┴──────┐                              ┌──────┴──────┐
   │ десктоп,    │                              │ сервер (VPS)│
   │ Android     │                              │ axum        │
   └──────┬──────┘                              └──────┬──────┘
          └────────────── notes-core (Rust) ───────────┘
            хранилище · компиляция Typst → HTML · ссылки · граф
```

### 2. Хранилище — папка с `.typ`, один Typst-проект

- Корень хранилища — корень Typst-проекта (`--root`). В нём лежит библиотека
  оформления `_konspekt/` и заметки по папкам-областям.
- **Заметка** — один `.typ` файл, компилируется отдельно: быстро, и сломанная
  заметка не валит остальные.
- **Книга** (большой конспект, как «Матан») — папка с `main.typ` и главами;
  отдельная сущность, чтобы главы не считались заметками.
- Ссылки между заметками — функция библиотеки (`#см("Сеть/SSH", "Туннели")`),
  которая оставляет `metadata`. Ядро собирает их запросом к документу: отсюда
  проверка ссылок **с якорями**, обратные ссылки и граф.

### 3. Отрисовка — HTML-экспорт Typst

- Текст — настоящий HTML: перенос под ширину экрана, поиск, выделение, якоря.
  Формулы — MathML (рисует браузер). Рисунки CeTZ — `html.frame`, то есть SVG,
  один в один как в PDF.
- В HTML-режиме (`target() == "html"`) библиотека выдаёт элементы с классами
  (`<div class="k-box k-def">`), а вид задаёт CSS. `grid`, `stack`, `place`,
  `v`, `h` в HTML-экспорте игнорируются, поэтому у каждого блока — своя HTML-ветка.
- Из того же исходника собирается PDF (печать, экзамен).

### 4. Темы: минимум две на заметку, переключение без перезагрузки

- Цвета текста, врезок и заголовков — CSS-переменные, `[data-theme=…]`.
- **Рисунки** (SVG) содержат вшитые цвета, и производные цвета (`lighten`,
  `transparentize`) на переменные не заменить. Поэтому заметка компилируется по
  разу на тему, а ядро склеивает результат: текст — из первой компиляции, у
  каждого рисунка — по варианту на тему, CSS показывает нужный. Порядок
  рисунков во всех компиляциях одинаковый, так что склейка простая.
- Подсветка кода: в HTML-режиме тема подсветки из «опорных» цветов, ядро
  заменяет их на CSS-переменные.
- Новая тема = словарь в `theme.typ` + блок переменных в CSS.

### 5. Интерактив — веб-компоненты

- Функция библиотеки выдаёт `html.elem("k-plot", attrs: (…))` — пользовательский
  HTML-элемент, который оживляет JS в цветах темы. В PDF — статичный рисунок
  со значениями по умолчанию.
- «Кадры»: рисунок CeTZ с параметром компилируется для N значений, ползунок
  переключает SVG. Стиль konspekt сохраняется полностью.
- План: 2D-калькулятор → кадры/анимации → 3D → (когда-нибудь) анимация
  алгоритмов и запуск кода.

### 6. Синхронизация и сервер — позже

- Сервер на Rust (axum) с тем же `notes-core`: отдаёт веб-версию и хранит
  хранилища пользователей.
- Синхронизация — версии файлов + блокировка на редактирование (одновременная
  правка одной заметки не нужна). CRDT не нужны.
- История версий и бекапы строятся на тех же версиях. Шифрование — далеко, не
  проектируем под него.

## Структура репозитория (цель)

```
crates/notes-core/   ядро: хранилище, компиляция, склейка тем, ссылки, граф
crates/notes-cli/    notes build | serve | check — работает без GUI
apps/desktop/        Tauri 2 (Linux, Windows, macOS, Android)
web/                 интерфейс (TS), общий для всех платформ
konspekt/            библиотека оформления (Typst), копируется в хранилище
examples/vault/      тестовое хранилище
docs/                архитектура и план
```

## Риски

- HTML-экспорт Typst экспериментальный: API `html.*` может меняться между
  версиями. Смягчение — закреплённая версия крейта, обновление осознанно, с
  прогоном тестового хранилища.
- Шрифты для веба (Gentium Plus, JetBrains Mono, New Computer Modern Math) нужно
  раздавать самим (woff2, лицензия OFL).
