## Следующая итерация (план на 2026-09-26)

Порядок — по приоритету. Перед началом — сверить с пользователем пункт 5.

1. ✅ **Вес страниц с рисунками** (пользователь считает это фундаментальным).
   Замер «Матана» до работ: страница 3,58 МБ, из них SVG 2,88 МБ (55 рисунков
   × 2 темы); глифы `<symbol>` — 1,09 МБ (1042 копии, уникальных 157); одна тема
   — 2,13 МБ; gzip всей страницы — 0,51 МБ. Шаги, каждый — с замером до/после:
   - [x] сжатие ответов сервера (gzip/brotli, `tower-http`): 3,71 → 0,28 МБ (br);
   - [x] глифы — один общий `<svg><defs>` на страницу вместо копии в каждом рисунке;
   - [x] **один SVG на все темы**: темы различаются только цветами — сравнить
         варианты рисунка, различающиеся цвета заменить на `var(--f-N)`, по
         теме — таблица значений. Если варианты отличаются не только цветом —
         прежняя склейка вариантов (запасной путь);
   - [x] настройка «точность рисунков»: Typst пишет координаты с 9 знаками после
         запятой; округление до 2–3 — сжатие с потерей, незаметной глазу.
         Растровый вариант для тяжёлых 3D-поверхностей — только если замер
         покажет, что векторный всё ещё тяжёл.

   Итог: 55 из 55 рисунков слились; страница 3,71 → 1,66 МБ (0,01 pt), по
   сети 0,21 МБ (br). Остаток — в основном MathML формул, не рисунки.
   Растр не понадобился.
2. ✅ **Закончить M1:** индекс ссылок по хранилищу (лениво, по версиям заметок) →
   API обратных ссылок и графа; оглавление заметки в клиенте (данные есть).
3. ✅ **Книга по главам:** страница на главу вместо одной длинной (первая сборка
   «Матана» ~14 с в отладочной сборке) + релизный профиль для замеров.

   Итог (релиз): первая сборка «Матана» 11,6 → 7,4 с (темы параллельно),
   после перезапуска — 0,045 с (кэш на диске `data/cache/`). Вёрстка в
   браузере: книга целиком ~0,4 с и 125 тыс. px; по главам — одна глава
   (настройка «Книги»), ссылки, оглавление и «назад» переключают главы.
4. ✅ **Библиотека оформления внутри бинарника** (сейчас путь указывает в
   репозиторий) — нужно до Tauri. И экспорт заметки в PDF из приложения.

   Итог: релизный бинарник самодостаточен (rust-embed, `konspekt/*.typ`),
   в отладочной сборке — каталог репозитория. PDF: `notes pdf <заметка>
   [--theme] [-o]`, `/api/pdf/{id}?theme=`, кнопка ⎙ (в текущей теме);
   «Матан» — 2,3 с, 2 МБ.
5. **Подготовка M2:** выбрать фреймворк интерфейса (рекомендация: Svelte 5 +
   TypeScript + Vite — лёгкий, без виртуального DOM, хорошо ложится на
   вставку готового HTML заметок) и способ связи Tauri ↔ ядро (встроенный
   сервер на localhost или IPC).
