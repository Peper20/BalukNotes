---
name: new-note
description: Завести в хранилище BalukNotes новую заметку или книгу на Typst и начать работу над ней по правилам `notes docs writing`. Вызывается из любой папки — часто из той, где лежат исходники (лекции, задачи).
disable-model-invocation: true
argument-hint: "[тема, путь в хранилище или «книга …»]"
allowed-tools: Bash(notes info), Bash(notes docs:*), Bash(notes list:*), Bash(notes tags), Bash(notes new:*), Bash(notes check:*), Bash(notes pdf:*), Bash(pdftoppm:*), Bash(pgrep -x notes), Read, Glob, Grep
---

Работай только через команду `notes` — не ищи исходники BalukNotes и
библиотеки `baluk`, не создавай файл заметки руками и ничего не
перезаписывай.

1. **`notes info`** — где хранилище и адрес приложения. Команды нет —
   скажи пользователю поставить BalukNotes (`tools/install.sh` в его
   репозитории) и остановись.
2. **Прочитай целиком** `notes docs writing` (как писать и проверять) и
   `notes docs library` (API библиотеки) — дальше работай по ним, не по
   памяти.
3. **Исходники.** Навык часто вызывают из папки с материалами: посмотри,
   что лежит в текущей папке (и что назвал пользователь), и прочитай
   относящееся к теме. Исходники только читай — в этой папке ничего не
   создавай и не меняй.
4. **Реши, что заводить**, из аргументов (`$ARGUMENTS`), разговора и
   исходников:
   - вид: **книга** (`--book`) — курс или большая тема с главами;
     **заметка** — одна тема (таблица «Заметка или книга» в
     `notes docs writing`);
   - путь в хранилище без `.typ` (`Папка/Название`): посмотри `notes list`
     и положи рядом с родственными;
   - название (`--title`, по умолчанию — последний сегмент пути), теги
     (`--tag`, можно несколько; в духе `notes tags`), язык (`--lang`, если
     не русский).

   Что очевидно — не спрашивай. Если вид или место неочевидны — один
   вопрос через AskUserQuestion: вариант по умолчанию первым, с путём и
   названием.
5. **`notes new [--book] [--title …] [--tag …] [--lang …] Путь`** — по коду
   выхода:
   - **0** — создано: в выводе — путь файла (дальше правь его) и адрес в
     приложении.
   - **1** — занято или путь недопустим: передай сообщение как есть и
     предложи другой путь. Мешающие файлы не удаляй и не правь.
   - **2** — ошибка в аргументах: исправь вызов (`notes new --help`).
6. **`notes check Путь`** — у заготовки нет ошибок и предупреждений.
7. **Покажи, где смотреть**: сервер запущен (`pgrep -x notes`) — адрес из
   вывода `notes new`, заметка обновляется сама по мере правок. Не
   запущен — предложи `notes serve` (можно в фоне).
8. **Начни работу** по разделу «Процесс» из `notes docs writing`: цель и
   читатель, исходники, план и «да» от пользователя — до этого текст
   заметки не пиши. После каждого шага обновляй шапку-комментарий в начале
   файла (у книги — `main.typ`); проверка — по разделу «Проверка».

Не хватает инструмента в библиотеке (рисунка, блока, раскладки) — не
рисуй своё в заметке: скажи пользователю, библиотеку правят отдельно, в
репозитории BalukNotes.
