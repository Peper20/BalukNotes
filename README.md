# baluk notes

Заметки на Typst с красотой печатных конспектов и удобством Obsidian:
ссылки, граф, быстрый переход, поиск — и интерактив, которого нет в PDF.
Браузер, десктоп и Android из одной кодовой базы (Rust + Tauri 2).

Сейчас есть: ядро на Rust компилирует хранилище `.typ` в HTML (светлая и
тёмная темы) и в PDF; локальный сервер с клиентом в браузере — дерево,
вкладки, поиск, оглавление, обратные ссылки, граф заметок, интерактивные
рисунки и кадры; статический сайт. Дальше — оболочка Tauri (M2) и Android
(M4), план — `docs/roadmap.md`.

## Быстрый старт: открыть приложение в браузере

1. **Поставить инструменты** (один раз): Rust ≥ 1.92 (`rustup`) и
   Node.js ≥ 22 с `npm`. Шрифты ставить не нужно — они встроены. Пакет
   Typst `@preview/cetz` скачается сам при первой сборке заметки с рисунком
   (нужен интернет).
2. **Собрать клиент** (один раз и после правок `app/`):
   ```sh
   npm --prefix app ci
   npm --prefix app run build        # → app/dist
   ```
3. **Запустить сервер** — одно из двух:
   ```sh
   # на тестовом хранилище из репозитория (готовые примеры всех возможностей)
   tools/test-env.sh                 # → http://127.0.0.1:8432

   # на своём хранилище: data/vault (создастся пустым, если нет)
   cargo run --release -p notes-cli -- serve    # → http://127.0.0.1:8421
   ```
   Первая сборка Rust — несколько минут. Заметки собираются при первом
   открытии (книга с рисунками — секунды), потом берутся из кэша.
4. **Открыть адрес** из вывода сервера в браузере. Остановить — Ctrl+C
   (или `kill $(pgrep -x notes)`).
5. **Добавить заметку** — файл `.typ` в `data/vault/` (папки — разделы):
   ```typst
   #import "/_baluk/lib.typ": *
   #show: note.with(title: [Моя заметка])

   = Раздел
   Текст, формулы $x^2$, ссылка на другую заметку: #see("Папка/Другая").
   ```
   Клиент подхватит её сам. Возможности библиотеки оформления —
   `baluk/README.md`, примеры — `tests/vault/`.

## Другие команды

```sh
cargo run -p notes-cli -- check                  # ошибки сборки и битые ссылки в хранилище
cargo run -p notes-cli -- build site/            # статический сайт → site/ (открывается и с диска)
cargo run -p notes-cli -- pdf Папка/Заметка --theme night   # PDF заметки или книги
cargo run -p notes-cli -- serve --token СЕКРЕТ   # сервер только с токеном (?token=СЕКРЕТ в адресе)
```

Общие флаги: `--vault <каталог>` — другое хранилище (например,
`tests/vault`), `--data <каталог>` — другой каталог данных (по умолчанию
`data/`: хранилище `vault/`, `settings.json`, кэш `cache/` — его можно
удалять). `--release` в `cargo run` — быстрее отрисовка, дольше сборка.

## Устройство

| Где | Что |
|---|---|
| `docs/architecture.md` | как устроено и почему: хранилище, отрисовка, темы, кэш, обновление |
| `docs/roadmap.md` | вехи: что сделано, что дальше |
| `docs/tech-debt.md` | что упрощено, чем грозит, как закрыть |
| `docs/questions.md` | открытые вопросы к пользователю по принятым решениям |
| `docs/research/` | отчёты исследований (E1–E3) с замерами |
| `crates/notes-core/` | ядро: хранилище, компиляция Typst, обработка HTML, кэш, прогрев, ссылки, граф, поиск, настройки |
| `crates/notes-server/` | HTTP API и раздача клиента (axum), модуль на область API |
| `crates/notes-site/` | статический сайт (`notes build`) |
| `crates/notes-assets/` | сборка клиента `app/dist` — общая для сервера и сайта |
| `crates/notes-cli/` | команда `notes`: serve, check, build, pdf |
| `app/` | клиент: Svelte 5 + TypeScript + Vite; `src/baluk-css/` — вид заметок |
| `baluk/` | библиотека оформления Typst: блоки, рисунки, шаблоны `note`/`book` |
| `fonts/` | шрифты оформления (встроены в бинарник) |
| `tests/vault/` | хранилище-фикстура: каждый случай отрисовки, каталог — его `README.md` |
| `tests/snapshots/` | эталонные снимки HTML фикстур |
| `tools/` | `check.sh` — полная проверка, `test-env.sh` — тестовый сервер, `visual.mjs`/`shot.mjs` — снимки страниц |

## Проверка

```sh
tools/check.sh          # всё: cargo test/clippy/fmt, notes check, типы API, клиент, e2e (~4 мин)
tools/check.sh --fast   # без сборки клиента и e2e; ещё есть --rust и --app
```

В конце — таблица «шаг → ок/упал, время», код возврата ненулевой при любой
ошибке; логи шагов — `tests/.data/check/`. Для e2e нужен системный
Chromium (`/usr/bin/chromium`, другой путь — `CHROMIUM=…`); Playwright
браузеры не скачивает.
