# baluk notes

Заметки на Typst с красотой печатных конспектов и удобством Obsidian:
ссылки, граф, быстрый переход, поиск — и интерактив, которого нет в PDF.
Typst компилирует ядро на устройстве (Rust): сейчас — `notes serve` на
своём компьютере с браузером, дальше — приложения Tauri для десктопа и
Android и браузер с ядром в WASM; сервер в сети — хранилище и вход.

Сейчас есть: ядро на Rust компилирует хранилище `.typ` в HTML (светлая и
тёмная темы) и в PDF; локальный сервер с клиентом в браузере — дерево,
вкладки, поиск, оглавление, обратные ссылки, граф заметок, интерактивные
рисунки и кадры. Дальше — сервер-хранилище с входом и
синхронизацией, затем приложения для десктопа и Android; план —
`docs/roadmap.md`.

## Быстрый старт

1. **Поставить инструменты** (один раз): Rust ≥ 1.92 (`rustup`) и
   Node.js ≥ 22 с `npm`. Шрифты ставить не нужно — они встроены. Пакет
   Typst `@preview/cetz` скачается сам при первой сборке заметки с рисунком
   (нужен интернет).
2. **Установить** команду `notes` и навык Claude Code `/baluk-note` (и
   после каждого обновления репозитория):
   ```sh
   tools/install.sh     # клиент, релизная сборка → ~/.local/bin/notes; навык → ~/.claude/skills/baluk-note
   ```
   Первая сборка Rust — несколько минут. Дальше `notes` работает из любой
   папки: библиотека оформления, клиент и шрифты встроены в бинарник.
3. **Запустить приложение**: `notes serve` → http://127.0.0.1:8421.
   Остановить — Ctrl+C (или `kill $(pgrep -x notes)`). Заметки собираются
   при первом открытии (книга с рисунками — секунды), потом берутся из
   кэша.
4. **Добавить заметку** — `notes new Папка/Название` (книга — `--book`)
   печатает путь файла; дальше — правьте его, приложение подхватит само:
   ```typst
   #import "/_baluk/lib.typ": *
   #show: note.with(title: [Моя заметка])

   = Раздел
   Текст, формулы $x^2$, ссылка на другую заметку: #see("Папка/Другая").
   ```
   С Claude Code — навык `/baluk-note` из папки с материалами: заведёт
   заметку или книгу и поведёт по правилам (цель, план, главы, проверка).
   Возможности библиотеки — `notes docs library`, как писать —
   `notes docs writing`.

## Команды

```sh
notes serve                          # приложение (http://127.0.0.1:8421); --token — только с токеном
notes new [--book] Папка/Название    # заготовка заметки или книги
notes list | notes tags              # заметки хранилища, теги
notes check [Папка/Заметка]          # ошибки сборки, предупреждения, битые ссылки
notes pdf Папка/Заметка --theme night -o x.pdf
notes docs writing | library         # как писать заметки, API библиотеки
notes info                           # где хранилище, настройки, библиотека
```

**Где данные.** Каталог данных — хранилище `vault/`, `settings.json`, кэш
`cache/` (его можно удалять) — по умолчанию `~/.local/share/baluk-notes`.
Другой — строкой в `~/.config/baluk-notes/config.toml`:

```toml
data = "~/Заметки"
```

Разово — `--data <каталог>` (или `NOTES_DATA`), другое хранилище —
`--vault <каталог>` (например, `tests/vault`).

**Из репозитория, без установки** — `cargo run -p notes-cli -- <команда>`
(отладочная сборка берёт `baluk/` и `app/dist` с диска — правки видны
сразу); тестовое хранилище с примерами всех возможностей —
`tools/test-env.sh` (http://127.0.0.1:8432).

## Устройство

| Где | Что |
|---|---|
| `docs/architecture.md` | как устроено и почему: хранилище, отрисовка, темы, кэш, обновление |
| `docs/roadmap.md` | вехи: что сделано, что дальше |
| `docs/tech-debt.md` | что упрощено, чем грозит, как закрыть |
| `docs/questions.md` | открытые вопросы к пользователю по принятым решениям |
| `docs/writing.md` | как писать заметки: содержание, рисунки, проверка (`notes docs writing`) |
| `docs/research/` | отчёты исследований (E1–E3) с замерами |
| `crates/notes-core/` | ядро: хранилище, компиляция Typst, обработка HTML, кэш, прогрев, ссылки, граф, поиск, настройки |
| `crates/notes-server/` | HTTP API и раздача клиента (axum), модуль на область API |
| `crates/notes-assets/` | сборка клиента `app/dist` для сервера |
| `crates/notes-cli/` | команда `notes`: serve, new, list, check, pdf, … |
| `app/` | клиент: Svelte 5 + TypeScript + Vite; `src/baluk-css/` — вид заметок |
| `baluk/` | библиотека оформления Typst: блоки, рисунки, шаблоны `note`/`book` |
| `skills/baluk-note/` | навык Claude Code `/baluk-note` (ставит `tools/install.sh`) |
| `fonts/` | шрифты оформления (встроены в бинарник) |
| `tests/vault/` | хранилище-фикстура: каждый случай отрисовки, каталог — его `README.md` |
| `tests/snapshots/` | эталонные снимки HTML фикстур |
| `tools/` | `check.sh` — полная проверка, `test-env.sh` — тестовый сервер, `visual.mjs`/`shot.mjs` — снимки страниц, `install.sh` — `notes` и навык в систему |

## Проверка

```sh
tools/check.sh          # всё: cargo test/clippy/fmt, notes check, заготовки заметок, типы API, клиент, e2e (~4 мин)
tools/check.sh --fast   # без сборки клиента и e2e; ещё есть --rust и --app
```

В конце — таблица «шаг → ок/упал, время», код возврата ненулевой при любой
ошибке; логи шагов — `tests/.data/check/`. Для e2e нужен системный
Chromium (`/usr/bin/chromium`, другой путь — `CHROMIUM=…`); Playwright
браузеры не скачивает.
