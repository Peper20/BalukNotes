# baluk notes — правила для агента

Приложение для заметок на Typst. Архитектура — `docs/architecture.md`, план и
текущая веха — `docs/roadmap.md` (отмечай сделанное там же).

## Главное

- Приоритет — **отрисовка**: заметка в HTML должна выглядеть как PDF konspekt.
  После любой правки библиотеки или CSS — собрать и **посмотреть глазами** обе
  темы и узкий экран:
  ```sh
  tools/build.py examples/vault build
  chromium --headless=new --hide-scrollbars --window-size=900,5000 \
    [--blink-settings=preferredColorScheme=0]  --screenshot=out.png file://$PWD/build/…
  ```
  (скриншоты — в scratchpad, не в репозиторий).
- Файлы заметок — источник правды. Приложение их не меняет молча.

## Библиотека `konspekt/`

- Форк `~/Documents/code/projects/konspekt-style/lib/`. Здесь теперь оригинал
  HTML-ветки; PDF-вид менять только осознанно и сверять с конспектами.
- У каждого блока две ветки: `context if веб() { … HTML … } else { … PDF … }`.
  В HTML — только разметка с классами `k-…` (помощник `эл` из `web.typ`),
  без цветов и размеров: их задаёт `web/konspekt.css`.
- В HTML-экспорте `grid`, `stack`, `align`, `place` **выбрасываются вместе с
  содержимым**. В библиотеке их в HTML-ветке не использовать; для чужой
  вёрстки шаблон ставит страховку (SVG-кадр `k-layout`).
- Внутри `html.frame` вёрстка снова постраничная — правила-страховки обязаны
  проверять `веб()`.
- Рисунки наследуют `set text` HTML-ветки шаблона (шрифт, кегль, **цвет**): без
  них подписи на SVG чёрные и не видны в тёмной теме. Проверять рисунки в «ночи».
- `return` в блоке отбрасывает стоящие перед ним `show`/`set` — оборачивай в `{ … }`.
- Цвета тем — только в `theme.typ`; для HTML их выгружает `css-цвета` → `css.typ`.
  Новая тема = словарь в `темы`, CSS-переменные появятся сами.
- Рисунки — только через `холст` (он оборачивает SVG в `div.k-frame`, по
  которому склеиваются темы).
- Копия библиотеки в хранилище (`_konspekt/`) — генерируемая, её не правят.
